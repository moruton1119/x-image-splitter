# X写真スタジオ

1枚の写真を横に2/3/4に分割して、X（旧Twitter）で大きく見える投稿画像を作るツール。
完全ローカル処理（サーバー不要・ファイル送信なし・CDN依存ゼロ）。

## 機能（シンプル設計）

1. 写真をドロップ - JPEG/PNG/WebP対応、向き自動補正
2. 横に2/3/4を選ぶだけ
3. プレビュー - Xのタイムラインでの実際の見え方を実測仕様で再現
   - 最初の2枚が並んで表示される現行Xのカルーセルを再現
   - 「1 / 4」ページカウンターと矢印ナビ
   - 1:1投稿との表示サイズ比較バー
   - 画像タップで拡大ビューア
4. ダウンロード - ZIP一括 / 1枚ずつ / X投稿画面を開く

画像は端末内（ブラウザ）でのみ処理され、どこにも送信されません。仕組み上、収集することもできません。

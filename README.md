# 🖼️✂️ X 分割くん

X（旧Twitter）で流行りの「1枚の写真を分割して大きく見せる投稿」を簡単に作るWebアプリ。
任意の分割レイアウト（1×4縦スライス等）に画像を自動トリミング。
**完全ローカル処理**（サーバー不要・ファイル送信なし）。

兄弟アプリ: [Discord 圧縮くん](https://github.com/moruton1119/discord-image-compressor)

## ✨ 機能

- 📎 ドラッグ&ドロップ or タップでアップロード（EXIF回転自動補正）
- 🀫 **分割レイアウト自由選択** — プリセット8種 + カスタム（行×列、最大4×4）
  - 流行りの **1×4 縦スライス** は自動提案（画像比率から最適レイアウトを判定）
- 🎯 **自動カバークロップ** — どの比率の画像でも任意レイアウトに自動フィット
  - セル比率: 1:1（正方形＝一番大きく見える）/ 4:5 / 2:3 / 16:9
  - クロップ位置をスライダーで微調整（横/縦オフセット）
- 🪝 **ギャップ補正** — Xのカルーセル表示で画像間に入る隙間をあらかじめ削る（0〜40px調整）。境界のズレ・欠けを防止
- 👀 **Xタイムライン風プレビュー** — 投稿後のカルーセル見え方をシミュレート
- 📦 出力: PNG / JPEG / WebP、品質・セル幅（640〜1440px）調整
- 🗂️ ZIP一括ダウンロード（STORE方式・ライブラリ自前実装で依存ゼロ）
- 🔢 **逆順DLオプション** — 保存フォルダで 1→2→3→4 の順に並び、添付ミスを防止
- ✏️ X投稿画面ワンクリックオープン

## 🚀 使い方

[GitHub Pagesのリンク](https://moruton1119.github.io/x-image-splitter/) にアクセスするだけ！

1. 写真をドロップ（おすすめレイアウトを自動適用）
2. レイアウト・比率・隙間を調整してプレビュー確認
3. ダウンロード → 出力画像を **1→2→3→4 の順** でXに添付
4. タップで縦に繋がる投稿の完成！

## 🛠️ 技術構成

| 機能 | 技術 |
|------|------|
| 画像読込 | createImageBitmap（EXIF回転対応） |
| トリミング/分割 | Canvas 2D API（カバークロップ+境界ギャップ削り） |
| ZIP生成 | STORE ZIP自前実装（依存ライブラリゼロ） |
| フロントエンド | HTML + Vanilla JS（依存ライブラリゼロ・CDN依存ゼロ） |
| デザイン | Open Design「x-ai」デザインシステム + Xブルー拡張 |
| ホスティング | GitHub Pages |

## 🔒 プライバシー

画像は**端末内（ブラウザ）でのみ処理**されます。サーバーへのアップロード・送信は一切ありません。

# 🖼️✂️ X 分割くん

X（旧Twitter）で流行りの「1枚の写真を分割して大きく見せる投稿」を簡単に作るWebアプリ。
任意の分割レイアウト（1×4縦スライス等）に画像を自動トリミング。
**完全ローカル処理**（サーバー不要・ファイル送信なし）。

兄弟アプリ: [Discord 圧縮くん](https://github.com/moruton1119/discord-image-compressor)

## ✨ 機能

- 📎 ドラッグ&ドロップ or タップでアップロード（EXIF回転自動補正）
- 🀫 **分割レイアウト自由選択** — プリセット8種 + カスタム（行×列、最大4×4）
- 🎯 **元画像の比率を維持したまま分割**（デフォルト）— COLLAGE方式
  - 例: 2048×2048 を **1×4（左→右4枚）** にすると各セル 512×2048 の縦長 → タイムラインで大きく表示
  - 縦長画像は **4×1（縦4段）** で各セル正方形 → 4ページに分けて読める投稿に
  - 画像比率から最適レイアウトを自動判定・適用
- ✂️ **セル比クロップはオプション**（4:5 / 3:4 / 1:1 / 16:9）— クロップ位置スライダー付き
- 👀 **X表示シミュレーションプレビュー** — 分割方法によって実際の見え方が変わります
  - **タイムライン表示**: Xのクロップ仕様を再現（縦長セル=高さMAXで大きく、横長=16:9で小さく）。カルーセル+ページングドット
  - **タップ後（拡大）**: 縦に繋がる見え方
  - **元の並び**: 分割前の復元イメージ
- 🪝 ギャップ補正（境界削り 0〜40px）
- 📦 出力: PNG / JPEG / WebP、セル幅（元のまま/640/1080/1440）
- 🗂️ ZIP一括ダウンロード（STORE方式・自前実装で依存ゼロ）
- 🔢 **逆順DLオプション** — 保存フォルダで 1→2→3→4 の順に並び、添付ミスを防止
- ✏️ X投稿画面ワンクリックオープン

## 🚀 使い方

[GitHub Pagesのリンク](https://moruton1119.github.io/x-image-splitter/) にアクセスするだけ！

1. 写真をドロップ（元画像の比率は維持されます。おすすめレイアウトを自動適用）
2. プレビューで**Xでの実際の見え方**（タイムライン/タップ後）を確認
3. ダウンロード → 出力画像を **1→2→3→4 の順** でXに添付
4. 縦長セルがタイムラインで大きく表示され、タップで繋がる投稿の完成！

## 🛠️ 技術構成

| 機能 | 技術 |
|------|------|
| 画像読込 | createImageBitmap（EXIF回転対応） |
| トリミング/分割 | Canvas 2D API（元比率維持の等分、オプションでカバークロップ） |
| X表示シミュレーション | 縦4:5〜横16:9のクロップ仕様をCSSで再現 |
| ZIP生成 | STORE ZIP自前実装（依存ライブラリゼロ） |
| フロントエンド | HTML + Vanilla JS（依存ライブラリゼロ・CDN依存ゼロ） |
| デザイン | Open Design「x-ai」デザインシステム + Xブルー拡張 |
| ホスティング | GitHub Pages |

## 🔒 プライバシー

画像は**端末内（ブラウザ）でのみ処理**されます。サーバーへのアップロード・送信は一切ありません。

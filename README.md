# 📸 X写真スタジオ

1枚の写真を**横に2/3/4に分割**して、X（旧Twitter）で大きく見える投稿画像を作るツール。
**完全ローカル処理**（サーバー不要・ファイル送信なし・CDN依存ゼロ）。

## ✨ 機能（シンプル設計）

1. **写真をドロップ** — JPEG/PNG/WebP対応、向き自動補正
2. **横に2/3/4を選ぶだけ** — それだけ！
3. **プレビュー** — Xのタイムラインでの実際の見え方を実測仕様で再現
   - 見切れ帯（「▲ 上 約28% 見切れ」を画像上に表示）
   - 「1 / 4」ページカウンター・◀▶矢印ナビ
   - 1:1投稿との表示サイズ比較バー（例: 1.8×）
   - 画像タップで拡大ビューア
4. **ダウンロード** — ZIP一括 / 1枚ずつ / X投稿画面を開く

## 🚀 使い方

[GitHub Pagesのリンク](https://moruton1119.github.io/x-image-splitter/) にアクセスするだけ！

## 🔒 プライバシー

画像は**端末内（ブラウザ）でのみ処理**されます。どこにも送信されません。

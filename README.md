# 📸 X写真スタジオ

X（旧Twitter）に投稿する写真を、「大きく見える分割投稿」に変換し、投稿前に実際の見え方を確認できるWebツール。
**完全ローカル処理**（サーバー不要・ファイル送信なし・CDN依存ゼロ）。

兄弟アプリ: [Discord 圧縮くん](https://github.com/moruton1119/discord-image-compressor)

## ✨ 機能

### ✂️ 分割タブ — 1枚の写真を大きく見せる
- **2つの分割モード**: 📱 カルーセル分割（左からN枚）/ 📖 段分割（上からN段）— 画像比率から自動判定
- **2つのスタイル**: 「写真を全部残す」（元比率維持）/ 「比率を揃える」（3:4・4:5 + 上下位置調整）
- **X実測表示仕様でプレビュー**: タイムラインの実際のクロップ範囲を再現（枚数別に異なる仕様）
  - 1枚: 元比率 / 2枚: 0.5〜1.5 / 3〜4枚: 0.56〜1.18（範囲外は「一部クロップ」バッジ表示）
- タップ後（拡大）ビュー、元の並びビュー
- 出力: PNG / JPEG / WebP、セル幅、ギャップ補正
- ZIP一括DL（自前実装）+ 逆順DL + 投稿画面ワンクリック

### 👁 プレビュータブ — 投稿前チェック
- 1〜4枚ミックス読込（縦横混在OK）、↑↓ボタンで並べ替え
- **見切れ警告**: 「左右 約X%ずつ見切れます」等を枚ごとに表示
- **iPhone風タイムライン**: 1枚/2枚横並び/カルーセルを実際のレイアウトで再現、タップで拡大ビューア
- **投稿文カウント**: X公式 twitter-text v3.1.0 同梱（URL 23文字・日本語2重み・280超=長文ポスト折りたたみ再現）
- 分割結果をそのままプレビューに持ち込む導線

## 🛠️ 技術構成

| 機能 | 技術 |
|------|------|
| 分割エンジン | Canvas 2D（元比率維持/カバークロップ、toBlob並列化） |
| X表示仕様 | iruagaru実測ベースの共通モジュール（枚数別クロップ範囲） |
| 文字数カウント | twitter-text v3.1.0（公式・同梱） |
| ZIP生成 | STORE ZIP自前実装（依存ゼロ） |
| デザイン | Open Design「x-ai」+ Xブルー拡張 |
| ホスティング | GitHub Pages |

## 🔒 プライバシー

画像は**端末内（ブラウザ）でのみ処理**されます。サーバーへのアップロード・送信は一切ありません。
